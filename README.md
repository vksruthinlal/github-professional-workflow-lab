
# GitHub Professional Workflow Lab

## Objective

Practice a professional Git and GitHub workflow using issues, milestones, project boards, branches, pull requests, code reviews, and merges.

## Tasks

1. Create Repository
2. Add README
3. Push to GitHub
4. Create Issue
5. Create Milestone
6. Create GitHub Project Board
7. Create feature-login Branch
8. Add Login Page
9. Push Branch
10. Create Pull Request
11. Review Pull Request
12. Request Changes
13. Update Code Based on Review
14. Approve Pull Request
15. Merge Pull Request
16. Close Issue

## Technologies

- Git
- GitHub
- HTML
- CSS
- JavaScript
